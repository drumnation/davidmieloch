# AI-Native Interview Challenge: Engineer

## Overview

Design and implement an AI-integrated responsive web application adhering to modern UI/UX principles. This challenge evaluates your ability to create engaging user interfaces, deal with dynamic data, and integrate an AI-powered feature.

### Context

You are tasked with building a responsive web application that allows users to interact with an AI-powered chatbot. The application should adhere to modern UI/UX principles, and the chatbot should be integrated using a provided API.

### Challenge Parameters
- **AI Maturity Level:** Intermediate
- **Format:** Take-home Challenge
- **Time Limit:** 4 Hours
- **AI Tools Allowed:** Yes
- **Team AI Fluency:** Familiar

## Challenge Description

Create a web application that:

1. Provides an engaging user interface for a chat application.
2. Includes a chatbot that interacts with users and provides responses via a provided API.
3. Allows users to initiate a chat, send messages, and receive responses from the chatbot.
4. Is responsive and provides a consistent user experience across different device sizes.

## Implementation Requirements

- Use a modern frontend framework (React, Vue, Angular, etc.)
- Implement a responsive design using CSS frameworks or CSS Grid/Flexbox.
- Integrate with the chatbot API (you can mock this with a delay).
- Include error handling for potential API failures.
- Write clean, maintainable, and well-documented code.
- Include basic tests for key components.

## Evaluation Rubric

### Technical Implementation (40%)
- **Excellent (35-40)**: Complete implementation with excellent UI/UX. Code is clean, well-structured, and follows best practices. Includes comprehensive tests.
- **Good (25-34)**: Solid implementation with good UI/UX. Code is clean, well-organized, and includes some tests.
- **Satisfactory (15-24)**: Basic implementation with acceptable UI/UX. Some parts of the code or tests need improvement.
- **Needs Improvement (0-14)**: Incomplete implementation, poor UI/UX, or significant issues with the code quality or tests.

### AI Integration & Workflow (30%)
- **Excellent (25-30)**: Sophisticated use of AI tools that significantly enhances productivity. Can explain AI prompt strategies and shows evidence of customizing/refining AI outputs.
- **Good (18-24)**: Effective use of AI tools that speeds up development. Shows understanding of how to prompt effectively and integrate AI outputs with existing code.
- **Satisfactory (10-17)**: Basic use of AI tools that helps with simple tasks. Some understanding of how to prompt effectively but may accept AI outputs without sufficient review or adaptation.
- **Needs Improvement (0-9)**: Ineffective use of AI tools or over-reliance on AI without understanding. Code shows signs of directly using AI outputs without proper integration or review.

### Communication & Documentation (30%)
- **Excellent (25-30)**: Exceptional documentation explaining design decisions, UI/UX choices, and AI integration strategy. Includes detailed README, inline comments where appropriate, and clear commit messages.
- **Good (18-24)**: Good documentation with a clear README and explanation of major design decisions. Some discussion of AI usage and workflow.
- **Satisfactory (10-17)**: Basic documentation that covers setup and usage but lacks depth on design decisions or AI workflow.
- **Needs Improvement (0-9)**: Minimal or missing documentation. Hard to understand code structure or design decisions.

## Interviewer Notes

### Key Questions to Ask

1. "Can you walk me through your design decisions for the UI/UX of the application?"
2. "How did you approach the integration of the AI-powered chatbot? What were the challenges you faced?"
3. "Can you explain your process for working with AI tools during this challenge? What were some effective prompts or strategies you used?"
4. "What was the most difficult part of the implementation and how did you overcome it?"
5. "If you had more time, what additional features or improvements would you make?"

### Red Flags

- Unable to explain parts of their own code (indicating over-reliance on AI without understanding)
- Direct copying of AI-generated code without adaptation to the specific requirements
- Poor UI/UX design showing lack of understanding of good practices
- No consideration for error handling or edge cases
- Lack of responsiveness or consideration for different device sizes

### Green Flags

- Thoughtful UI/UX design showing understanding of modern design principles
- Strategic use of AI tools that enhances rather than replaces their own thinking
- Evidence of iterative improvement and learning during the development process
- Well-structured code with clear separation of concerns
- Consideration of error handling, edge cases, and user experience
- Bonus points for additional features or enhancements that weren't explicitly required
