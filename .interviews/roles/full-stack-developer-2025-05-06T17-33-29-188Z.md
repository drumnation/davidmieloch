# AI-Native Interview Challenge: Full Stack Developer

## Overview

As a Full Stack Developer, you are expected to have proficiency in both frontend and backend development. This challenge is designed to assess your skills in building a cross-platform application that works consistently across web, mobile, and desktop environments. The focus of this challenge will be on web frontend development.

### Context

Our organization is building a cross-platform application that needs to work consistently across different platforms. For this challenge, you will be tasked with creating a sample component of this application.

### Challenge Parameters
- **AI Maturity Level:** Beginner
- **Format:** Live-Coding
- **Time Limit:** 2 Hours
- **AI Tools Allowed:** No
- **Team AI Fluency:** Expert

## Challenge Description

Your task will be to design and implement a responsive user registration form that works consistently across different platforms (web, mobile, desktop). This form should take in user details (name, email, password, confirm password) and submit this data to a mock backend server.

## Implementation Requirements

- Use a modern JavaScript framework/library (React, Vue, Angular, etc.) for the frontend
- The form inputs should have appropriate validation (e.g., email format, password matching, etc.)
- The form should be responsive and render appropriately on different screen sizes
- Implement a mock backend server using Node.js and Express.js
- The form should send a POST request to the backend server upon successful validation

## Evaluation Rubric

### Technical Implementation (40%)
- **Excellent (35-40)**: The form is fully functional with all validation working correctly. The form is responsive and displays correctly on different screen sizes. The backend server handles the POST request correctly and responds appropriately.
- **Good (25-34)**: The form and backend server are functional but there may be minor issues with validation or responsiveness.
- **Satisfactory (15-24)**: The form and backend server are mostly functional but there are noticeable issues with validation or responsiveness.
- **Needs Improvement (0-14)**: The form or backend server are not functional or there are major issues with validation or responsiveness.

### Communication & Documentation (30%)
- **Excellent (25-30)**: All code is well-documented and easy to understand. The design decisions and implementation process are clearly communicated.
- **Good (18-24)**: Most of the code is documented and the design decisions and implementation process are mostly clear.
- **Satisfactory (10-17)**: Some parts of the code are documented and the design decisions and implementation process are somewhat clear.
- **Needs Improvement (0-9)**: The code lacks documentation and the design decisions and implementation process are not clear.

### Live Coding Performance (30%)
- **Excellent (25-30)**: The candidate codes efficiently and effectively, demonstrating a clear understanding of the task. They communicate their thought process clearly and handle any challenges or issues smoothly.
- **Good (18-24)**: The candidate codes well and demonstrates an understanding of the task. They mostly communicate their thought process well and handle most challenges or issues effectively.
- **Satisfactory (10-17)**: The candidate codes somewhat effectively and demonstrates some understanding of the task. They somewhat communicate their thought process and handle some challenges or issues.
- **Needs Improvement (0-9)**: The candidate struggles with coding or understanding the task. They do not communicate their thought process well and do not handle challenges or issues effectively.

## Interviewer Notes

### Key Questions to Ask

1. "Can you explain your design decisions for the user registration form?"
2. "How did you ensure the form would display correctly on different screen sizes?"
3. "Can you describe how the form validation works?"
4. "How does the form interact with the backend server?"
5. "If you had more time, what improvements would you make?"

### Red Flags

- Struggles with basic JavaScript, HTML, or CSS concepts
- Does not understand how to make a form responsive
- Does not understand how to validate form inputs
- Struggles with creating a basic backend server
- Cannot explain their own code or design decisions

### Green Flags

- Demonstrates a strong understanding of JavaScript, HTML, and CSS
- Understands how to make a form responsive
- Understands how to validate form inputs
- Can create a functional backend server
- Can clearly explain their own code and design decisions
