# AI-Native Interview Challenge: Tech Lead

## Overview

For this challenge, you will be designing and implementing a responsive web-based dashboard that visualizes a set of AI-powered analytics. This task evaluates your ability to lead technical projects, make architectural decisions, and integrate AI-powered features in a modern frontend context.

### Challenge Parameters
- **AI Maturity Level:** Intermediate
- **Format:** Take-home Challenge
- **Time Limit:** 4 Hours
- **AI Tools Allowed:** Yes
- **Team AI Fluency:** Familiar

## Challenge Description

You need to create a React application that:

1. Pulls data from a provided mock API, which returns AI-generated analytics data.
2. Visualizes this data in a dashboard using a charting library like Chart.js or D3.js.
3. Implements responsive design to ensure the dashboard is usable on desktop and mobile devices.
4. Includes interaction elements, like filters and dropdowns, to manipulate the view of the data.

## Implementation Requirements

- Use React with TypeScript for the project.
- Implement a state management solution to handle application state.
- Leverage a charting library to visualize data.
- Ensure the dashboard is responsive and works across different device sizes.
- Write clean, maintainable code with clear documentation.
- Include unit tests for key components and functionality.

## Evaluation Rubric

### Technical Implementation (40%)
- **Excellent (35-40)**: Complete implementation with advanced features like dynamic chart transitions, smooth responsiveness, and excellent performance. The code is clean, well-structured, and adheres to best practices.
- **Good (25-34)**: Solid implementation with all core features working well. The code is clear, well-structured, and follows good practices.
- **Satisfactory (15-24)**: Basic implementation with core functionality working, but some areas could be improved for cleaner code or better organization.
- **Needs Improvement (0-14)**: Incomplete implementation or significant issues with core functionality. The code structure and organization need substantial improvement.

### AI Integration & Workflow (30%)
- **Excellent (25-30)**: Expert use of AI throughout the project, using AI prompts effectively, integrating AI outputs seamlessly into the codebase, and refining AI output for better results.
- **Good (18-24)**: Effective use of AI in the project, with good prompting and integration of AI outputs. Shows understanding of how to work with AI tools.
- **Satisfactory (10-17)**: Basic use of AI that helps with simple tasks. Some understanding of how to prompt effectively, but may accept AI outputs without sufficient review or adaptation.
- **Needs Improvement (0-9)**: Ineffective use of AI or over-reliance on AI without understanding. Code shows signs of directly using AI outputs without proper integration or review.

### Communication & Documentation (30%)
- **Excellent (25-30)**: Exceptional documentation explaining design decisions, component architecture, and AI integration strategy. Includes a detailed README, inline comments where appropriate, and clear commit messages.
- **Good (18-24)**: Good documentation with a clear README and explanation of major design decisions. Some discussion of AI usage and workflow.
- **Satisfactory (10-17)**: Basic documentation that covers setup and usage but lacks depth on design decisions or AI workflow.
- **Needs Improvement (0-9)**: Minimal or missing documentation. Hard to understand code structure or design decisions.

## Interviewer Notes

### Key Questions to Ask

1. "Can you explain your architectural decisions for this project and how you structured your components?"
2. "How did you decide on the state management solution for this application? What were the alternatives?"
3. "What was your strategy for integrating AI capabilities into this project? Can you share some examples?"
4. "What challenges did you face during the implementation and how did you overcome them?"
5. "If you had more time, what features or improvements would you add?"

### Red Flags

- Unable to explain parts of their own code (suggests over-reliance on AI without understanding)
- Directly copied AI-generated code without adapting to the project requirements
- Poorly designed components or insufficient state management that indicate lack of architectural thinking
- Ignored edge cases or error handling, indicating potential issues with quality control
- Did not leverage TypeScript effectively for type safety

### Green Flags

- Well-designed components and state management demonstrating strong understanding of React patterns
- Strategic use of AI tools to accelerate development without compromising code quality
- Iterative development process with clear evidence of learning and improvement
- Clean, well-structured code with clear separation of concerns
- Consideration for user experience, performance, and edge cases
- Bonus: Implemented extra features or enhancements beyond the basic requirements
