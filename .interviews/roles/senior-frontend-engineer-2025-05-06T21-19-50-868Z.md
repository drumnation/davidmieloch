# AI-Native Interview Challenge: Senior Frontend Engineer

## Overview

The challenge involves developing a responsive web application with a modern UI/UX that integrates AI-powered features. This challenge tests your ability to leverage AI tools in your workflow, catering to the role of a Senior Frontend Engineer.

### Context

The project entails building a web application that integrates an AI chatbot to answer customer queries and guide users through the website.

### Challenge Parameters
- **AI Maturity Level:** Intermediate
- **Format:** Take-home Challenge
- **Time Limit:** 4 Hours
- **AI Tools Allowed:** Yes
- **Team AI Fluency:** Familiar

## Challenge Description

Develop a web application using React and TypeScript that includes:

1. A responsive layout that adjusts to different screen sizes.
2. Integration of an AI chatbot that can answer predefined questions and guide users.
3. A contact form that validates user input and submits data to a mock API endpoint.
4. Unit tests for the main components.

## Implementation Requirements

- Use React with TypeScript for development.
- Implement a responsive design for mobile and desktop viewports.
- Integrate an AI chatbot (you can use a mock service or a platform like Dialogflow).
- Create a contact form with validation for each field.
- Submit form data to a mock API endpoint.
- Write unit tests for at least the contact form and the chatbot integration.

## Evaluation Rubric

### Technical Implementation (40%)
- **Excellent (35-40)**: Complete implementation with responsive design, chatbot integration, form validation, and unit tests. Code is clean, well-organized, and utilizes TypeScript effectively.
- **Good (25-34)**: Solid implementation with most of the core features. Code is organized and follows good practices, with minor areas for improvement.
- **Satisfactory (15-24)**: Basic implementation with some core functionality. Code organization and structure need improvement.
- **Needs Improvement (0-14)**: Incomplete implementation or significant issues with core functionality. Code structure and organization need substantial improvement.

### AI Integration & Workflow (30%)
- **Excellent (25-30)**: Effective use of AI tools to accelerate development. Can explain AI prompts and strategies, and shows evidence of refining AI outputs.
- **Good (18-24)**: Good use of AI tools that contributes to speed of development. Shows understanding of how to prompt AI effectively.
- **Satisfactory (10-17)**: Basic use of AI tools that aid in simple tasks. Some understanding of how to prompt AI but may accept AI outputs without sufficient review.
- **Needs Improvement (0-9)**: Ineffective use of AI tools, or over-reliance on AI without understanding.

### Communication & Documentation (30%)
- **Excellent (25-30)**: Exceptional documentation outlining design decisions, component architecture, and AI integration strategy. Includes a detailed README, inline comments, and clear commit messages.
- **Good (18-24)**: Good documentation with clear README and explanation of major design decisions. Some discussion of AI usage and workflow.
- **Satisfactory (10-17)**: Basic documentation that covers setup and usage but lacks depth on design decisions or AI workflow.
- **Needs Improvement (0-9)**: Minimal or missing documentation. Code structure or design decisions may be difficult to understand.

## Interviewer Notes

### Key Questions to Ask

1. "Can you walk me through your design process for this application?"
2. "How did you decide on the AI chatbot integration approach?"
3. "What strategies did you use to prompt the AI during development?"
4. "What were the challenges you faced during this task, and how did you overcome them?"
5. "Given more time, what improvements would you make?"

### Red Flags

- Unable to explain parts of their own code or design decisions.
- Over-reliance on AI-generated code without proper integration or review.
- Poor structure or organization of code, indicating lack of planning or understanding.
- Lack of consideration for user experience or responsive design.
- Inadequate or missing unit tests.

### Green Flags

- Well-designed and organized code, indicating careful planning and understanding.
- Effective use of AI tools to speed up development.
- Thoughtful and user-focused design, showing understanding of modern UI/UX principles.
- Good unit test coverage and understanding of testing principles.
- Strong communication and documentation skills.
