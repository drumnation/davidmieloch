# AI-Native Interview Challenge: Data Scientist

## Overview

This challenge evaluates your ability to analyze, interpret, and visualize real-time sensor data from IoT devices for a mobile app interface.

### Context

The project involves designing a mobile app that integrates with IoT devices and displays real-time data from sensors.

### Challenge Parameters
- **AI Maturity Level:** Intermediate
- **Format:** Take-home Challenge
- **Time Limit:** 1 Hour
- **AI Tools Allowed:** No
- **Team AI Fluency:** Familiar

## Challenge Description

Your task is to analyze a dataset from IoT sensors and create visualizations to display the data on a mobile app interface. You should consider the following:

1. Analyze the dataset to understand the characteristics and patterns.
2. Create meaningful and easy-to-understand visualizations.
3. Provide insights about the data.
4. Write a brief report explaining your findings and how you would present them on a mobile app interface.

## Implementation Requirements

- Use Python for data analysis and visualization.
- Your code should be clean, well-documented, and easy to understand.
- The visualizations you create should be suitable for a mobile app interface.
- The report should be concise, engaging, and easy to understand.

## Evaluation Rubric

### Technical Implementation (40%)
- **Excellent (35-40)**: Complete and thorough analysis with insightful visualizations. Code is exceptionally clean, well-structured, and follows best practices.
- **Good (25-34)**: Solid implementation with good analysis and visualizations. Code is clean, well-organized, and follows good practices.
- **Satisfactory (15-24)**: Basic implementation with some analysis and visualizations. Some areas could be improved for cleaner code or better organization.
- **Needs Improvement (0-14)**: Incomplete implementation or significant issues with analysis or visualizations. Code structure and organization need substantial improvement.

### Data Interpretation & Visualization (30%)
- **Excellent (25-30)**: Sophisticated interpretation of data with insightful visualizations suitable for a mobile app interface. 
- **Good (18-24)**: Good interpretation of data with decent visualizations suitable for a mobile app interface. 
- **Satisfactory (10-17)**: Basic interpretation of data with simple visualizations suitable for a mobile app interface.  
- **Needs Improvement (0-9)**: Inadequate interpretation of data or visualizations not suitable for a mobile app interface.

### Communication & Documentation (30%)
- **Excellent (25-30)**: Exceptional documentation explaining data findings, visualization choices, and how they would be presented on a mobile app interface. Includes detailed README, inline comments where appropriate, and clear commit messages.
- **Good (18-24)**: Good documentation with clear README and explanation of major findings and visualization choices. Some discussion of how they would be presented on a mobile app interface.
- **Satisfactory (10-17)**: Basic documentation that covers setup and usage but lacks depth on findings or visualization choices.
- **Needs Improvement (0-9)**: Minimal or missing documentation. Hard to understand findings or visualization choices.

## Interviewer Notes

### Key Questions to Ask

1. "Can you explain your process for analyzing the data? What patterns or insights did you find?"
2. "Walk me through your chosen visualizations. Why did you choose these and how do they contribute to understanding the data?"
3. "How did you consider the mobile app interface when creating your visualizations?"
4. "What challenges did you face during this task and how did you overcome them?"

### Red Flags

- Unable to explain their analysis or visualization choices
- Visualizations are overly complex or confusing
- Poorly structured or hard to understand code
- No consideration for how visualizations would appear on a mobile app interface

### Green Flags

- Clear and concise explanation of data analysis and visualization choices
- Visualizations are simple, engaging, and easy to understand
- Consideration of the mobile app interface when creating visualizations
- Clean, well-documented, and easy-to-understand code
