# The Code My Fingers Can Afford

## Premise
I spent the last year teaching AI to write code the way I like it written.

Now I'm practicing for a React live coding test and running into a weird split in my own head.

One part of me is the architect who trained the model:
- explicit naming
- strong separation of concerns
- thoughtful abstractions
- nitpicky rules
- readable, polished structure

The other part of me is sitting in a timed manual coding environment thinking:
- every extra line costs me time
- every abstraction has to justify the keystrokes
- I can feel my body optimizing for survival
- I am making conscious decisions to type less, not necessarily to write the code I would actually want in the codebase

That tension feels important.

## Core idea
This isn't just "AI made me rusty."

It's more like:

> I trained myself into being an editor of ideal code, not a typist of economical code.

Manual coding selects for a different architecture than AI-assisted coding.
Not always worse. But definitely different:
- more compressed
- more local
- more tactical
- less willing to pay abstraction costs up front

## Possible angles

### Angle 1 — Interview pressure changes architecture
When you're typing by hand under time pressure, you stop optimizing for ideal structure and start optimizing for survival. The architecture shifts because the cost model shifts.

### Angle 2 — AI changed my sense of what "good" feels like
After spending a year specifying how I want code written, hand-authoring everything again feels oddly expensive. The gap between the code I want and the code my fingers can afford becomes visible.

### Angle 3 — The job market is still testing for a pre-agent skill profile
There's something strange about being evaluated on manual code production after you've already moved upstream into system design, rule design, and agent orchestration.

## Strong lines / quotes to keep

> I can feel my body optimizing for survival in the interview environment.

> I start making lots of conscious decisions to type as little as possible instead of writing the code I would have had AI type for me.
